# Lift Log

A free, installable workout tracker (PWA) for home and gym training.

**Open it:** https://sloqa5.github.io/Workout-app/

## Install on your phone
- **Android (Chrome):** open the link → menu ⋮ → **Install app** (or "Add to Home screen").
- **iPhone (Safari):** open the link → Share → **Add to Home Screen**.

It works offline once installed. Updates arrive automatically: when a new version is pushed here, the app shows an **Update** banner next time you open it online.

## Features
- Setup questionnaire (goal, experience, days, gym vs home, equipment, session length, focus areas, injuries) that builds a tailored plan, or hands it to Claude to design
- Routines with rotation ("Up next"), routine builder (sets, rep range, rest, supersets, reorder), duplicate/delete
- 118 exercises plus your own custom exercises, with search, muscle/equipment filters and how-to video links
- Workout logging: last session's numbers, auto rest timer with beep/vibrate, warm-up sets, drop sets, failure sets, supersets, per-exercise notes, swap and add exercises mid-workout, plate calculator, live PR alerts
- Smart progression: rep-range double progression, Easy/Good/Hard ratings, welcome-back deloads, stall detection
- Coach insights, muscle recovery, weekly sets per muscle, strength and body-weight charts, history
- AI coach via Claude: copy your data with a ready-made prompt (weekly check-in, workout review, stalled lifts, design a routine) and paste routines back in
- Backup/restore (JSON) and CSV export

## Sharing
Anyone can use it: send them the link. Each person's data stays on their own phone and the questionnaire builds their own plan.

## Data
Everything is stored in your phone's browser storage. Export a backup from Settings now and then.
